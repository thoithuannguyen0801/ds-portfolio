# ds-portfolio

A modern, responsive personal portfolio for a **Data Science student** — Home, About, Projects, and Contact pages with a dark/light theme, animated data‑viz charts, a skills section, and a one‑click resume download.

Built with **Next.js (App Router) + TypeScript + Tailwind CSS v4**. Deploys to **Vercel** with zero configuration.

## Features

- **4 pages** — Home, About, Projects, Contact
- **Dark / light theme** with a no‑flash toggle (defaults to dark, remembers your choice)
- **Custom data‑viz** — radar chart, activity bar chart, and animated skill bars (hand‑built SVG/CSS, no chart dependency)
- **Filterable projects** grid by category
- **Resume download** button (served from `public/resume.pdf`)
- **Responsive** layout with a mobile nav, accessible focus states, and reduced‑motion support
- **SEO‑ready** metadata + Open Graph
- Everything is content‑driven from a single file: [`src/lib/content.ts`](src/lib/content.ts)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Make it yours

Almost all edits happen in one place — **`src/lib/content.ts`**. Search for `TODO` to find the things you most likely want to change:

1. **Profile** — name, role, tagline, summary, location, email.
2. **Socials** — GitHub / LinkedIn / Kaggle / email links and handles.
3. **Skills** — the proficiency bars (`skills`) and the radar chart (`skillRadar`).
4. **Projects** — title, summary, tags, metrics, and demo/repo/report links.
5. **Education & experience** — the timelines on the About page.
6. **Stats / highlights / activity** — the numbers and the activity chart on Home & About.
7. `site.url` — set this to your real deployed URL for correct SEO/Open Graph.

Other assets:

- **Resume:** replace `public/resume.pdf` with your real CV. (A placeholder is generated by `npm run resume:placeholder`.)
- **Avatar (optional):** drop a photo at `public/avatar.jpg` and set `profile.avatar = "/avatar.jpg"`.

### Theming

Colors are defined as CSS variables in [`src/app/globals.css`](src/app/globals.css) (`:root` for light, `.dark` for dark) and exposed to Tailwind via `@theme`. Tweak `--primary`, `--accent`, etc. to rebrand the whole site.

## Deploy to Vercel

1. Push this repo to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repository — Vercel auto‑detects Next.js, so no extra config is needed.
3. After the first deploy, copy your URL into `site.url` in `src/lib/content.ts` for accurate metadata.

Or deploy from the CLI:

```bash
npm i -g vercel
vercel        # preview deployment
vercel --prod # production deployment
```
